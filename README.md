Intro to PowerBI course through Datacamp for MIS 561, completed on 9/28. https://public.tableau.com/app/profile/sanjana.shahreen/viz/PowerBITrainingCertifications_17907403271130/PowerBIStory. In Flex 4, I built my Tableau dashboard's interactivity by hand: I created a filter action so selecting a service tier updated every other view, set each filter card to apply to all the relevant worksheets, and added a context filter so the Top N account filter ran before the other filters. Power BI does this by default, because visuals on the same report page cross-filter each other through the data model with no configuration. For a similar interactive dashboard that a sales leader will explore on their own, I would choose Power BI next time - because every manual link is a place where a filter can silently miss a worksheet and leave the dashboard showing numbers that don't agree, and a published report keeps the linked behavior for viewers who never open my file. I would still choose Tableau for a single explanatory chart where I need full control over the visual design, as I did with my Flex 4 applied chart.
