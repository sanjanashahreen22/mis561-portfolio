Intro to PowerBI course through Datacamp for MIS 561, completed on 9/28. https://public.tableau.com/app/profile/sanjana.shahreen/viz/PowerBITrainingCertifications_17906664959340/PowerBIStory . Something I liked about Power BI is that it cross-filters visuals on the same page by default, while Tableau requires manually configured filter actions and Excel requires linking each filter to specific PivotTables or charts. That means less setup time and no broken filter links, so I'll use Power BI for dashboards people explore on their own and keep Tableau for cases that need customized visuals.
