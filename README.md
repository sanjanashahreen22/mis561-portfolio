Intro to PowerBI course through Datacamp for MIS 561, completed on 9/28. https://public.tableau.com/app/profile/sanjana.shahreen/viz/PowerBITrainingCertifications_17906664959340/PowerBIStory. In Flex 4, I built the interactivity on my Tableau Account Portfolio dashboard by hand: I set each filter card to apply to every worksheet it should control, added a context filter so my Top N filter on accounts ran before the other filters, and created a filter action so that selecting one of the three service tiers updated every other view across all 793 accounts. Power BI does this by default, because visuals on the same report page cross-filter each other through the data model with no configuration. For a dashboard a sales leader will explore on their own, I would choose Power BI next time, because each manual link is a place where a filter can silently miss a worksheet or run in the wrong order, so the reader sees a different set of accounts than they think they are looking at, and a published report keeps the linked behavior for viewers who never open my file. I would still choose Tableau for a single explanatory chart where I need full control over the design, as with my Flex 4 applied chart.
